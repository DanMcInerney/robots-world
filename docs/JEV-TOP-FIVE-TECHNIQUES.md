# Five Jev techniques to test for camera-based drone control

Saved 19 September 2026. This is the durable ranking from the follow-up discussion, ordered by expected applicability to one MAVLink drone using one or two cameras to find and follow the same requested car near 10 m. It is a hypothesis ranking, not measured flight performance. The underlying sources and limits are in the [ecosystem audit](JEV-ECOSYSTEM-TECHNIQUES-AUDIT.md); the perception/execution architecture is in the [camera-follow recommendation](JEV-CAMERA-FOLLOW-RECOMMENDATION.md).

| Rank / stable ID | Technique | Proposed drone use | First isolated test |
| --- | --- | --- | --- |
| 1 / T1 | Jev chooses the next missing evidence | Choose fresh depth, appearance comparison or a revealing viewpoint when current evidence cannot support movement or identity. Perception supplies measurements; Jev chooses the evidence request or view. | Same initial observation and evidence budget; compare a fixed next observation with a Jev-selected one. Score whether the new evidence resolves the actual decision, as well as false commitments and added latency. |
| 2 / T2 | Separate best candidate from any valid match | Select a relative best visible car separately from whether any observed car is sufficiently supported as the original target. Keep ambiguous, no match and incomplete coverage distinct. | Same candidate records: target present, all lookalikes, target absent and ambiguous evidence. Compare a single Choice with a none option against the same Choice plus an independent adequacy question. |
| 3 / T3 | Revalidate the facts the selected maneuver depends on | Check goal/target identity, observation age and the relevant clearance/range/visibility envelope immediately before applying a delayed decision. | Same proposed decision and delayed observation stream; vary irrelevant background changes, target changes, hazard entry, expiry, Stop and goal changes. Compare age-only, whole-snapshot and action-dependency checks. |
| 4 / T4 | Separate hold/move from conditional maneuver selection | Ask hold/move and, independently, which complete maneuver would be appropriate assuming movement. Code consumes the maneuver only when move was selected. | Keep the physical actions and consequences fixed while duplicating equivalent movement options or reordering IDs. Compare a flat menu with conditional factorization; keep hold available in both. |
| 5 / T5 | Distinguish continue, change and restart | Preserve a productive pursuit job and its history across decisions; explicitly change or restart it when warranted. Continue required MAVLink refreshes and expiry checks. | Same measured execution trace and command capabilities; compare concrete operation descriptions against explicit continue/change/restart wording. Measure progress, needless resets and response to actual failure or changed goals. |

Sources: [jev-code evidence questions](https://github.com/devagrawal09/jev-code/blob/fd092558ebea389c81d44f9b10e826d9a72afaa3/src/workflows/find.ts#L423-L501); [WrongStack relative/absolute fit](https://github.com/WrongStack/WrongStack/blob/4cf97c0aa4f855751949ee8e99c719d06f4c26e0/packages/core/src/coordination/typesafe-dispatch-classifier.ts#L80-L159); [Cline action freshness](https://github.com/abeatrix/cline-plugin-jev-browser/blob/c886dcb35cb7d64d682a56211f9b04a5345c6433/src/jev-browser.ts#L353-L411); [Jevpilot conditional resolution](https://github.com/standardagents/jevpilot/blob/e1beeb13b9a928fb76f167f86af584f4ce9cf180/src/planning.js#L403-L444); [Jevscape routine control](https://github.com/Skyvern-AI/jevscape/blob/8fe4d37349fc6a8d03ac1c918302eef254bb56c3/agents/jev/controller.ts#L690-L788).

The later discussion promoted continue/change/restart into this top five; memory compression remains a lower-priority follow-up. Do not silently substitute the earlier audit's five section headings for these stable technique IDs.

T3 passed its finite dispatcher gate; T1 needs a freshness-focused follow-up; T2/T4/T5 showed no incremental benefit. The hypothesis ranking above remains unchanged for reference.
